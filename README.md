# My Library Hub

My Library Hub is a React-based web application that allows users to explore and manage their favorite books.

## Features

- Home Page
- Books Page
- Add Book Page
- About Page
- React Router Navigation
- Responsive Layout

## Technologies Used

- React
- React Router DOM
- Vite
- JavaScript
- CSS

## Sample Books

- A Good Girl's Guide to Murder — Holly Jackson
- We Can Be Strangers Again — Shrijeet Shandilya
- Atomic Habits — James Clear
